# 统计理论基础：极大似然估计 · 混合分布模型 · 群体推断

> **学习目标**：理解 Liang et al. (2024) 论文中三个核心统计概念，并能用 R 语言实现基本框架
> **前置知识**：概率论基础（条件概率、贝叶斯定理）、基础统计推断
> **阅读时间**：约 45 分钟

## 0. 先给你一个"地图"

在开始之前，先用一个直觉类比把三个概念串起来。

你面前有一袋豆子，有些红豆（人类写的），有些绿豆（AI 写的）。你只能隔着一层磨砂玻璃看——看不清单个豆子的颜色，但可以看到整袋豆子混合后的色相。

- **极大似然估计（MLE）** 回答的问题是：**"给定我看到的这袋混合豆子的颜色，最合理的红豆/绿豆比例是多少？"**
- **混合分布模型** 是这件事的数学表达：**"我如何用数学语言描述一袋混合豆子的颜色分布？"**
- **群体推断** 回答了一个更根本的问题：**"为什么我不一个个挑豆子判断颜色，而是直接估计整袋的比例？"**

这三个概念在论文中不是孤立的——混合模型是框架，MLE 是求解方法，群体推断是研究视角。下面逐个拆解。

## 第一部分：极大似然估计（Maximum Likelihood Estimation, MLE）

### 1.1 直觉：抛硬币的故事

抛一枚硬币 10 次，观察到 7 次正面。你觉得这枚硬币正面朝上的概率 p 是多少？

你的直觉告诉你：p ≈ 0.7。但为什么是 0.7 而不是 0.5 或 0.9？

MLE 的回答是：**在所有可能的 p 中，p = 0.7 使"观察到 7 次正面"这件事发生的概率最大。**

更形式化地说：
- 在 p = 0.5 时，观察到 7 正面的概率是 C(10,7) × 0.5^7 × 0.5^3 = 0.117
- 在 p = 0.7 时，观察到 7 正面的概率是 C(10,7) × 0.7^7 × 0.3^3 = 0.267
- 在 p = 0.9 时，观察到 7 正面的概率是 C(10,7) × 0.9^7 × 0.1^3 = 0.057

p = 0.7 时概率最大 → **0.7 就是 MLE 估计值**。

### 1.2 数学定义（三句话说清楚）

设有数据集 X = {x₁, x₂, ..., xₙ}，来自参数为 θ 的分布。定义**似然函数**：

$$L(\theta) = P(X \mid \theta) = \prod_{i=1}^{n} P(x_i \mid \theta)$$

**极大似然估计**就是找到使 L(θ) 最大的 θ 值：

$$\hat{\theta}_{MLE} = \arg\max_{\theta} L(\theta)$$

因为连乘在计算上不好处理（容易下溢），实际中通常最大化**对数似然**：

$$\hat{\theta}_{MLE} = \arg\max_{\theta} \sum_{i=1}^{n} \log P(x_i \mid \theta)$$

> 为什么加 log 不影响结果？因为 log 是单调递增函数，f(x) 取最大值的地方，log(f(x)) 也在同一个地方取最大值。

### 1.3 在这篇论文中 MLE 是怎么用的？

论文中，θ 换了个名字叫 **α**（AI 生成文本的比例）。数据不是硬币正反面，而是**每个形容词的出现与否**。

具体来说：

1. **已知两件事**：
   - 在纯人类评审中，形容词 w 出现的概率是 $p_w^{(H)}$
   - 在纯 AI 评审中，形容词 w 出现的概率是 $p_w^{(AI)}$

2. **未知一件事**：
   - 在 ChatGPT 发布后的混合语料库中，AI 文本的占比 α

3. **混合模型**：在混合语料库中，形容词 w 出现的概率为：
   $$P(w) = (1 - \alpha) \cdot p_w^{(H)} + \alpha \cdot p_w^{(AI)}$$

4. **似然函数**：遍历所有形容词，计算在给定 α 下观察到当前语料库中每个形容词出现次数的联合概率，然后最大化之。

### 1.4 R 实现：从抛硬币到论文框架

```r
# ============================================================
# 示例 1：抛硬币 MLE（入门）
# ============================================================
# 抛 10 次硬币，7 次正面，估计 p

# 方法一：解析解 p_hat = 7/10 = 0.7
p_hat_analytic <- 7 / 10

# 方法二：数值优化（更通用的方法）
neg_loglik_coin <- function(p, n_heads = 7, n_total = 10) {
  # 返回负对数似然（因为 optim 默认最小化）
  -dbinom(n_heads, size = n_total, prob = p, log = TRUE)
}

result <- optim(
  par     = c(p = 0.5),       # 初始猜测
  fn      = neg_loglik_coin,   # 目标函数
  method  = "Brent",           # 一维搜索
  lower   = 0, upper = 1
)

cat(sprintf("抛硬币 MLE: p = %.3f\n", result$par))
# 输出：p = 0.700


# ============================================================
# 示例 2：论文框架的简化版 MLE（两个形容词）
# ============================================================
# 假设我们只关注两个形容词："commendable" 和 "meticulous"

# --- 步骤 1：从参考语料库估计 P(w|H) 和 P(w|AI) ---
# 纯人类评审中每个形容词的出现概率
p_H <- c(commendable = 0.01, meticulous = 0.02)

# 纯 AI 评审中每个形容词的出现概率
p_AI <- c(commendable = 0.10, meticulous = 0.25)

# --- 步骤 2：在混合语料库中统计形容词出现次数 ---
# 假设混合语料库有 1000 句评审
n_total <- 1000

# 实际观察到的次数
obs_counts <- c(commendable = 60, meticulous = 120)

# --- 步骤 3：定义负对数似然函数 ---
neg_loglik_mixture <- function(alpha) {
  # 混合概率
  p_mix <- (1 - alpha) * p_H + alpha * p_AI
  
  # 对数似然：每个形容词的出现次数服从二项分布
  ll <- 0
  for (word in names(p_H)) {
    ll <- ll + dbinom(obs_counts[word], size = n_total, prob = p_mix[word], log = TRUE)
  }
  return(-ll)
}

# --- 步骤 4：数值优化求解 ---
result2 <- optim(
  par     = c(alpha = 0.1),
  fn      = neg_loglik_mixture,
  method  = "Brent",
  lower   = 0, upper = 1
)

cat(sprintf("\n论文框架 MLE: alpha = %.3f\n", result2$par))
# 输出大约：alpha ≈ 0.105（即约 10.5% 的 AI 占比）

# --- 步骤 5：验证 ---
# 手工验证：alpha=0.10 时，P(commendable) = 0.9×0.01 + 0.1×0.10 = 0.019
# 1000×0.019 = 19，但我们观察到 60。这严重偏离！
# 这说明必须用实际的 p_H 和 p_AI 值，示例数据是编的
```

> **小提示**：论文实际用的形容词远不止 2 个（附录里列了 Top 100），每个形容词独立贡献一个二项对数似然项，总的似然是所有形容词的和。

## 第二部分：混合分布模型（Mixture Distribution Model）

### 2.1 直觉：两包豆子倒进一个袋子

你有两包豆子：
- 红包装：每颗豆子有不同"色号"的概率
- 绿包装：每颗豆子有不同"色号"的概率

你从红包装里倒了 90% 的豆子进袋子，从绿包装倒了 10% 进袋子，然后摇匀。

**问题**：随机从袋子里摸一颗豆子，它是某个特定色号的概率是多少？

**答案**：$P(\text{色号}) = 0.9 \times P(\text{该色号} \mid \text{红包}) + 0.1 \times P(\text{该色号} \mid \text{绿包})$

这就是混合分布模型——一个分布是多个子分布的加权平均。

### 2.2 数学形式

一个含有 K 个分量的混合模型：

$$P(x) = \sum_{k=1}^{K} \pi_k \cdot P_k(x)$$

其中：
- $\pi_k$ 是第 k 个分量的**混合权重**，满足 $\sum_{k=1}^{K} \pi_k = 1$ 且 $\pi_k \geq 0$
- $P_k(x)$ 是第 k 个分量的**概率分布**

论文中的情况是最简单的 **K = 2**（只有人类和 AI 两个分量）：

$$P(w \mid \alpha) = (1 - \alpha) \cdot P(w \mid \text{Human}) + \alpha \cdot P(w \mid \text{AI})$$

### 2.3 关键假设：条件独立性

论文有一个重要的隐含假设：**给定 α，不同形容词的出现相互独立。**

这意味着两个形容词同时出现的联合概率可以简单地相乘：

$$P(w_1, w_2 \mid \alpha) = P(w_1 \mid \alpha) \times P(w_2 \mid \alpha)$$

这个假设在现实中不一定严格成立（`commendable` 和 `meticulous` 可能有相关性），但作者做了大量稳健性检验（换不同词性、换不同词集），证明结果不依赖于这个假设的严格成立。这是应用统计中一种典型的"工程折中"——假设不完全对，但足够用。

### 2.4 与高斯混合模型（GMM）的关系

你可能在聚类分析中学过高斯混合模型（GMM），那是混合模型的一个特例——每个分量都是高斯分布。

这篇论文的混合模型更简单：每个分量为形容词的**多项分布**（或近似为多个独立二项分布），但思想完全一致：

| | GMM | 本文方法 |
|---|---|---|
| **分量分布** | 高斯分布 N(μₖ, σₖ²) | 形容词多项分布 |
| **混合权重** | πₖ（待估） | (1-α, α)（α 待估） |
| **求解方法** | EM 算法 | 直接 MLE（分量参数已知） |
| **为什么更简单** | 分量参数也未知 | 分量参数从参考语料库预估计 |

> 论文方法之所以不需要 EM 算法，是因为**人类和 AI 两个分量的参数 p_H 和 p_AI 已经从参考语料库中预先估计好了**，唯一未知的是混合权重 α。如果你要在没有参考语料库的情况下做这件事，那就需要 EM 了。

### 2.5 R 实现：可视化混合分布

```r
# ============================================================
# 可视化：混合分布如何随 α 变化
# ============================================================

# 模拟数据：10 个形容词在人类和 AI 文本中的概率
set.seed(42)
words <- c("commendable", "meticulous", "intricate", "notable",
           "versatile", "innovative", "pivotal", "profound",
           "laudable", "holistic")

# 人类文本中的概率（较低且均匀）
p_human <- runif(10, 0.005, 0.03)
names(p_human) <- words

# AI 文本中的概率（显著更高，且高度集中在前几个词）
p_ai <- c(0.12, 0.09, 0.07, 0.06, 0.05, 0.04, 0.03, 0.02, 0.01, 0.01)
names(p_ai) <- words

# 不同 α 下的混合概率
compute_mixture <- function(alpha) {
  (1 - alpha) * p_human + alpha * p_ai
}

# 展示对比
alphas <- c(0, 0.05, 0.10, 0.15, 0.30)
mixture_table <- sapply(alphas, compute_mixture)
colnames(mixture_table) <- paste0("alpha=", alphas)
rownames(mixture_table) <- words

print(round(mixture_table, 4))
# 可以看到：随着 alpha 增大，"commendable"等词的频率明显上升
# 这就是论文 Figure 1 想表达的核心信号

# 简单可视化
barplot(
  height = mixture_table[, "alpha=0.10"],
  names.arg = words,
  las = 2, cex.names = 0.7,
  main = "混合分布中的形容词概率 (alpha=10%)",
  col = "steelblue"
)
```

## 第三部分：群体层面的统计推断（Population-Level Inference）

### 3.1 核心思想转变

这是整篇论文最值得你品味的思维方式。

**个体分类的思路**：
```
审稿意见 → [分类器] → 人类写的 / AI写的
```
问题是：你需要判断"每一篇"，但分类器准确率不高。

**群体估计的思路**：
```
大量审稿意见 → [统计模型] → 约 10.6% 是 AI 生成/修改的
```
你不需要知道"哪 10.6%"，只需要知道"有 10.6%"。

### 3.2 为什么群体估计比个体分类更可靠？

类比：流行病学监测。

- **个体诊断**：给每个人做新冠检测，试剂盒有假阳性和假阴性。
- **群体监测**：随机抽样测群体抗体阳性率，用统计学方法校正误差。

在样本量足够大的时候，群体估计的误差可以很小——因为**个体的随机误差在大样本中互相抵消**。

论文做到了什么程度？他们构造了已知 α 的人工语料库做验证，预测误差不超过 **1.8 个百分点**。这意味着他们说"ICLR 评审有 10.6% 是 AI 修改的"时，真实值大概率在 8.8%~12.4% 之间。

### 3.3 Bootstrap 置信区间

论文不仅给出了点估计 α̂，还报告了 Bootstrap 置信区间。Bootstrap 的核心思想是：

1. 从原始数据中有放回地重复抽样（比如 1000 次）
2. 每次抽样后用同样的 MLE 方法估计一个 α
3. 这 1000 个 α 的分布就是 α̂ 的抽样分布
4. 取 2.5% 和 97.5% 分位数，得到 95% 置信区间

这种方法不依赖大样本近似（如 Fisher 信息矩阵求渐近方差），在小样本或分布不规则时更可靠。

### 3.4 R 实现：Bootstrap 置信区间

```r
# ============================================================
# Bootstrap 置信区间（结合前面的 MLE 框架）
# ============================================================
library(boot)

# 模拟数据：一个 1000 句混合语料的形容词出现次数
set.seed(123)
n_total <- 1000
true_alpha <- 0.106   # 论文 ICLR 的估计值

# 生成模拟观测：每条评审对每个形容词，按混合概率随机生成
generate_mixture_data <- function(alpha, p_H, p_AI, n) {
  replicate(n, {
    if (runif(1) < alpha) p_AI else p_H
  })
}

simulated_probs <- t(generate_mixture_data(true_alpha, p_human, p_ai, n_total))
simulated_counts <- colSums(matrix(rbinom(
  n_total * length(p_human), 1, as.vector(simulated_probs)
), nrow = n_total))

# 定义 MLE 函数（返回 α 的点估计）
estimate_alpha <- function(counts, p_H, p_AI, n) {
  neg_loglik <- function(alpha) {
    p_mix <- (1 - alpha) * p_H + alpha * p_AI
    -sum(dbinom(counts, size = n, prob = p_mix, log = TRUE))
  }
  optim(par = 0.1, fn = neg_loglik, method = "Brent",
        lower = 0, upper = 1)$par
}

# Bootstrap
B <- 1000
boot_alphas <- numeric(B)
for (b in 1:B) {
  # 有放回重抽样counts
  boot_counts <- rmultinom(1, sum(simulated_counts), prob = simulated_counts)
  boot_alphas[b] <- estimate_alpha(boot_counts, p_human, p_ai, n_total)
}

# 结果
ci_lower <- quantile(boot_alphas, 0.025)
ci_upper <- quantile(boot_alphas, 0.975)

cat(sprintf("\nBootstrap 结果：\n"))
cat(sprintf("  点估计 alpha = %.4f\n", estimate_alpha(simulated_counts, p_human, p_ai, n_total)))
cat(sprintf("  95%% CI = [%.4f, %.4f]\n", ci_lower, ci_upper))
cat(sprintf("  （真实值 = %.4f）\n", true_alpha))

# 可视化 Bootstrap 分布
hist(boot_alphas, breaks = 30, probability = TRUE,
     main = "Bootstrap 抽样分布",
     xlab = expression(hat(alpha)),
     col = "lightblue", border = "white")
abline(v = true_alpha, col = "red", lwd = 2, lty = 2)  # 真实值
abline(v = c(ci_lower, ci_upper), col = "blue", lwd = 2, lty = 3)  # CI
legend("topright",
       legend = c("真实值", "95% CI", "Bootstrap分布"),
       col = c("red", "blue", "lightblue"),
       lty = c(2, 3, NA), pch = c(NA, NA, 15), lwd = c(2, 2, NA))
```

## 第五部分：对论文方法的批判性思考

作为一个统计专业的学生，你应该培养批判性阅读论文的习惯。以下问题值得思考：

### 5.1 形容词的独立性假设真的合理吗？

论文假设不同形容词独立，但实际上形容词之间有相关性。论文用多种方式做了稳健性检验（换词性、换词集、随机子集），但这只是"证据表明影响不大"，不是严格证明。

**思考题**：如果形容词之间有正相关，对 α 的估计会产生什么偏误？

### 5.2 p_H 和 p_AI 是固定的吗？

论文用 ChatGPT 发布前的评审估计 p_H，用 ChatGPT 生成的评审估计 p_AI。但如果人类在 ChatGPT 发布后也开始使用一些 AI 爱用的词（潜移默化的影响），p_H 就会随时间变化，导致估计偏差。

### 5.3 个体推断的缺失

群体估计告诉你"约 10.6% 是 AI 修改的"，但如果你导师想知道"这篇具体的评审有没有用 AI"，这个方法就帮不了你。这是该方法的一个固有限制。
